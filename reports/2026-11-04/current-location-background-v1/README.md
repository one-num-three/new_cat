# 当前位置与后台定位授权修订 · 2026-11-04

## 行为

- 新建通用场地打开范围编辑页，先用一次 GCJ-02 定位居中；在编辑页切换到通用地图也适用。不会自动指定集合点或创建边界。
- 已保存的集合点、已有房间和美术场地保留原视角；用户已拖图、选点、切换地图或离页时，迟到的定位结果不覆盖操作。
- 定位拒绝或失败保留手动选点与“用我位置”。初始居中不受50米开局/抓捕门槛限制，不上传初始定位。
- 对局启动后台定位前，依次申请 scope.userLocation、scope.userLocationBackground，授权成功后调用 startLocationUpdateBackground。等待授权时不重复发起 getLocation。拒绝或接口失败明确降级前台，退出或结束后清理逻辑保持。

## 真机待验与配置

账号此前反馈尚未开通后台定位，当前账号权限状态未重新读取。需在微信公众平台“开发管理 → 接口设置”开通 startLocationUpdateBackground，隐私指引写明前后台定位用途，再让用户同意后台定位。系统弹窗名称/可选项由微信与操作系统控制，代码不能强制“始终允许”，也不能保证系统不降低后台频率。

微信接口依据：https://github.com/TencentLBS/tencentmap-miniprogram-skill/blob/main/references/wx_location_api/wx.startLocationUpdateBackground.md

1. 在南京以外打开“使用实时地图 → 范围编辑”，应移到当前设备位置，尚无自动集合点。
2. 拒绝位置权限后应可手动拖图框选，迟到GPS不得拉走视角；已有场地不应跳到本人位置。
3. 账号权限开通后，Android/iOS分别在真实对局授权后台定位；锁屏/离开微信数分钟，核查另一端的位置时间与服务器采样。系统可能节流，不能以模拟授权代替此项。
4. 出局、退出、取消和终局后确认定位停止；拒绝后台授权时确认前台模式提示和设置入口。
