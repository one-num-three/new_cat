## 来源与定位

用户选定 [小程序图标探索板 02-01](design/2026-10-09/brand-exploration/02_小程序图标_12款.png) 作为后续小程序的视觉基准：明亮天空、草地、公园路线、圆润的橘白小猫与小鼠、扁平卡通造型。可运行客户端使用 [独立图标](assets/brand/selected-icon.png)；同风格的页面预览在 `design/2026-10-09/brand-exploration/07_已选风格_页面预览.png`。生图预览不是微信运行截图，文字与规则必须以客户端和服务端为准。

本基线覆盖首页、房间、地图、动态码、异常状态、结算、图标和动效。现有玩法仍由 `pilot-0.2` 服务端规则裁决；视觉图不增加游戏能力。

## 视觉规则

| 用途 | 基准色 | 用法 |
| --- | --- | --- |
| 页面底色 | `#F5FAF1` | 户外阅读的浅暖绿白 |
| 文字 | `#213638` | 主标题、数字、重要状态 |
| 猫与主动作 | `#F36A34` | 猫队、主要按钮、抓捕确认 |
| 鼠与成功 | `#286B47` / `#EAF7DC` | 鼠队、准备与成功，必须同时配图形或文字区分含义 |
| 天空与信息 | `#DDF3FF` | 首页插画、邀请区域、非紧急说明 |
| 本人位置 | `#3D9BE8` | 地图上仅表示本人，不能复用为敌方点 |
| 警示 | `#FFF0E4` + 深橘文字 | 近距预警、需要注意的操作 |

- 形状：大块扁平色面、圆角卡片和柔和曲线；小图标优先明确剪影。插画可有云、草地和小路，但主动作与地图文字之下不铺复杂背景。
- 字体：系统中文无衬线；标题重、数字清楚，正文最小字号以真机大字体测试为准。文字不能依赖颜色单独表达身份或结果。
- 页面：地图优先，顶部放阵营、目标和时间，底部只保留当前主动作；名单、事件和操作放抽屉。安全区、小屏和户外日光优先于装饰。
- 功能图标参考 [当前玩法组件探索](design/2026-10-09/selected-style-system/01_当前玩法组件图标.png)。生图图标只是形态参考，发布前须统一矢量轮廓、状态色与 32/48px 识别度；示意二维码不可用作抓捕码。

## 动效规则

动效关键帧以 [校正版分镜](design/2026-10-09/selected-style-system/03b_动效关键帧_校正版.png) 为参考；可播放样片见同目录的四段 GIF。早期 `03_动效关键帧探索.png` 曾在区域内画出橘色中心点，**不采纳该表达**。

| 场景 | 表现 | 边界 |
| --- | --- | --- |
| 躲藏转追逐 | 状态条与倒计时轻切换，约 200ms | 阶段切换由服务端确定，动画不能提前宣告开局 |
| 区域线索 | 宽泛橘色透明区域淡入，约 240ms | 区域内不出现鼠的精确点、头像或方向箭头 |
| 近距猫预警 | 底部警示条滑入，约 200ms | 不给猫的坐标、距离、方位或身份；不得遮挡主动作 |
| 抓捕确认 | 服务端确认后面板上移，勾选与进度只播放一次 | 请求中不提前播放成功；重放/旧快照不能重复动效或增加计数 |

不用频闪、持续雷达扫描、密集粒子或持续弹跳。断网、暂停和大字体模式优先静态清晰状态。所有关键事实必须在动画结束后仍有文字显示。
