# 中途补员动态捕获目标 · reinforce-v2

2026-10-19。本地API0.5.2，线上仍0.5.0，未部署、上传或发布。实施、184项自动回归和MCP连续取证完成；见 verification.json、index.html 与19张原始截图。

## 规则变更

用户要求覆盖 reinforce-v1 的开局固定目标。基础 pilot-0.3 参数不变，本轮新增试点策略 reinforce-v2：

| 本局累计成员 | 阵营 | 右上角（尚未抓捕） |
| --- | --- | --- |
| 8人开局 | 2猫6鼠 | 0/4 |
| 第9人补鼠 | 2猫7鼠 | 0/5 |
| 第10人补猫 | 3猫7鼠 | 0/5 |
| 第11人补鼠 | 3猫8鼠 | 0/5 |
| 第12人补鼠 | 3猫9鼠 | 0/6 |

- 捕获目标=ceil(本局累计加入鼠人数×60%)，累计鼠人数包括待定位、活跃、被捕和退出者。成功入房的同一事务立即更新目标，定位成功后才能实际抓捕或被捕。入场30秒超时仍退出本局。
- 新猫同步阵营人数；鼠人数不变时，按鼠人数计算的目标不变。阵营继续由服务端按开局比例分配，客户端不能指定角色或目标。新增人数不代表规则已经平衡。
- 重复入房、重连不重复增加人数/目标；掉线、退出、入场超时不降低目标，防止用重入/退出改变胜利门槛。原阵营和截止不变。
- 房间事务锁串行处理补员和抓捕：补员先提交则用新目标；胜利先确认则不重开，不追加本局参与者或改旧结果。截止先到则按鼠胜处理，加入不能延时。
- 新局保存reinforce-v2与targetMouseCount；旧进行中局在下次成功补员时切到v2并重算，已有终局和历史文档不改写。结果保存最终目标及累计鼠人数。
