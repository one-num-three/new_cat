# 地图余量与真实本人定位

## 已实现

- 艺术地图四向增加72–120逻辑像素的停留余量。继续外拉有逐渐增强的阻尼，额外形变限制在80像素内；松手220ms回弹到余量边界。整图缩放、双指切换、取消、回弹中再次接手均共用相机，图片与标记保持等比，标记锚点不变。露出的区域为浅纸色，没有新增虚构地理内容。
- 公共「场地地图」增加定位、图层、停止三个图标。按定位才申请前台定位；连续位置与首个高精度请求均显式GCJ-02。蓝爪只表示手机采集的本人位置，显示精度与原始GCJ-02坐标，不需要开房或登录，不上传、不存储，不改变对局。
- 图片使用既有OSM参考模型，覆盖外不猜测点位，明确提示切换真实地图。真实地图也使用同一个蓝爪。手动拖动后不被更新强制拉回，点定位图标回到本人。
- 离页、切后台、停止后移除订阅/定时器并清空点位，10秒无新位置会清空过期点。迟到请求、旧订阅失败不会恢复旧位置或干扰新订阅，重复清理不会停止其他页面后来开启的定位。
- 对局原有连续定位补显式 `type:'gcj02'`；保持服务端授权和原有上报频率，不把公共导览的本机定位用于抓捕/胜负。

## 真机操作

1. 在微信开发者工具打开 `D:\cat-mouse-miniprogram`，编译后使用「真机调试」。本轮未自动上传或发布。
2. 首页 → **场地地图** → 选择实际所在场地。
3. 点地图右上方的定位准星图标，允许微信定位，并开启手机定位服务。此处不会使用开发调试台的模拟玩家点。
4. 查看蓝爪、精度和GCJ-02坐标，缓慢走动核对。图片覆盖外时，点下面的图层图标看真实地图；关闭图标停止定位。离开页面后返回需重新点定位。
5. 对局页仍依赖真实后端及授权快照；本次公共导览走点不依赖后端升级。两校区模型仍未实地验收，不能把显示出蓝爪等同地理精度通过。

若微信提示定位权限或接口申请未完成，需要在该真实AppID的微信平台配置中核对定位与隐私声明。现有app.json已声明getLocation/startLocationUpdate/onLocationChange；本轮未伪造平台获批或真机结果。坐标参数核对依据：[微信官方API类型定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)。
