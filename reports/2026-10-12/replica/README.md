本轮把已选的 16 张页面 / 状态稿实现为现有小程序的原生控件，不是另建演示 App。正式流程继续使用 `pilot-0.2` 授权快照、真实地理地图、服务端抓捕凭据与结算。保留原工作树，未推送、未发布、未部署。

## 明早怎么看

微信开发者工具项目目录：`D:\cat-mouse-miniprogram`。选择「界面调试台」编译模式并编译，进入 14 个核心状态；猫 / 鼠地图的「队伍 · 规则」按钮打开第 16 张详情抽屉。首页、创建、准备和码页均为实际 WXML/WXSS 页面，可输入、改人数、切准备、开局、返回和打开抽屉。普通编译进入真实首页；只有开发版接受预览参数。体验 / 正式版不开放调试台。

## 差异和待确认

1. 生图稿中的字形与手机系统字体不是同一个字体文件；使用系统中文黑体和可缩放原生文字，未称逐像素相同。
2. 为分层原生实现，插画被模型派生成无字资产，云 / 树 / 路径与原整页 PNG 有局部差异；统一背景在所有开发地图状态复用。正式玩法使用实际地图，不能显示虚构公园作为真实位置。
3. 首页预览保留空输入框；动态码预览不可扫描，实际码由服务器生成。暂停 / 再开仅组织者可见，不照搬稿中对所有人的按钮。
4. 1.3 文字倍率使调试台滚动，不强行缩小字号塞进一屏；滚动到底可到达返回动作。320px 真机仍在下一次验收清单。
5. IDE 的旧元素 offset / 输入接口曾超时；改用官方选择器和有界路由等待，处理器调用不等待被页面切换销毁的 RPC Promise。失败日志保留，不计通过。模拟器曾「突然变小」的 IDE 窗口根因仍未确认；本轮没有移动或缩放桌面窗口，不宣称修好 IDE 本身。
