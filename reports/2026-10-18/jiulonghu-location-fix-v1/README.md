# 九龙湖范围误报复现与修复

## 原因与实现

反馈坐标 **GCJ-02：31.882368,118.828049** 确实通过所选校区范围检查。换算到近似WGS84为31.8844491761,118.8229326940，靠近已保存OSM的梅园7B建筑中心（约5米）。旧模型只覆盖20个控制点围出的凸包，遗漏了东南区域；“图面内/校园内”不等于“旧控制网内”。旧project返回null能够复现，原提示缺少这个区分。

已用原画与保存OSM重新对照梅园5C、梅园1C、东侧田径场3地标，生成v2控制网，保留所有原20点和全部原画。现在反馈点约落在1254原图 **(1076.07,967.31)**，梅园7B附近；周围±20米九点均可映射。没有修改输入坐标、硬贴边、拿用户位置做拟合或取消覆盖检查。

新模型23点/36分区、无折叠；独立于拟合的两个图面/OSM检查点误差约1.18/2.91px。它们仍来自同一图片和OSM，**不能证明实地GPS精度**，fieldVerified=false。其他未覆盖区域仍拒绝映射，提示改为校区内尚未完成图片配准，避免暗示用户已离开校园。
