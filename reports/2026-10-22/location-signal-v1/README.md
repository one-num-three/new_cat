# 定位小信号与精度数值

2026-10-22，本地前端修订。API仍0.6.1，后端规则未变，未部署/上传。

- 地图固定HUD下方左侧、准备页按钮上方，显示四级小信号格与`±12m`形式的精度数值；点信号查看具体原因。
- 4格：0<精度≤5米；3格：5<精度≤10米；2格：10<精度≤25米；1格：精度>25米。颜色为绿/黄/橙，不依赖颜色单独传达状态。数值向上取整，未知或0精度不伪装满格。
- 分档是本项目的界面显示规则，不是平台规定的卫星信号等级或实测准确率。
- 本地定位回调超过5秒未更新、未授权、未同步、范围外、跳变、样本未通过校验、出局/退出/结算分别展示灰色原因。更新年龄是本机收到定位回调后的时间，不代表底层卫星测量时间。
- 仍使用微信`accuracy`估计值，**不是卫星信号强度、百分比，也不保证真实误差一定落在±范围内**。接口语义参考[腾讯位置服务文档](https://github.com/TencentLBS/tencentmap-miniprogram-skill/blob/main/references/wx_location_api/wx.getLocation.md)。
- 服务端现有精度≤25米及位置≤5秒有效期保持；超过25米的样本照常由服务端拒绝。准备/抓捕/敌点权限都不由信号格决定，没有额外GPS请求、网络轮询或后台授权变化。

## 实现

`location-v2`在本机保存精度/回调时间/本地顺序/上报状态，状态中不含经纬度。即便样本被拒绝，也能显示真实的`±60m`；不再将此类问题统一写成地图上的“定位中断”。旧身份/旧对局/卸载后的回调被拦截，慢手动请求不能覆盖更新的定位流数值。暂停仍可重新采集，但不会因此恢复对局；断网立即灰显，终局停止采集。

地图复用既有倒计时刷新检查过期，准备页复用既有请求/快照，不新增定时器。全局注册一个小组件，不需要图片素材或新依赖。
