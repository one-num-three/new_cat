# EVT-A 磁吸四线柔性转接

电路板展开尺寸 9.60 × 13.089911 mm。基材选用 25 µm PI 双铜层、0.5 oz 名义铜厚、总厚 0.12 mm，黄覆盖膜与沉金焊盘。正面两个端子排均为 2.54 mm 节距的四个 Ø1.30 mm 焊盘。反面为 GND 回流面，两个 Ø0.30 mm 通镀孔位于平直端。按 2 层柔性板询价，拼板由供应方确认。[嘉立创柔性板工艺能力](https://jlcpcb.com/capabilities/flex-pcb-capabilities)

| 触点 | 信号 | 整机 X (mm) |
|---|---|---:|
| 1 | +5V | −3.81 |
| 2 | GND | −1.27 |
| 3 | USB D− | +1.27 |
| 4 | USB D+ | +3.81 |

两端使用同一铜面，绕 X 轴静态折弯后分别朝向底壳触点和主板底面 J1。贴合端子前核对针一，按装配图施焊。折弯内侧的两个切点距展开板端各 3.55 mm，中心线弯曲半径 1.20 mm。弯折区无过孔、器件或补强，批量定型前需确认实际叠层和折弯工具。

零件在 Strap-Halo 和 Velcro Lite 装配中均编号 17。OCCT 对折弯包络进行几何检查，名义最小间隙为马达 0.125 mm、底壳 0.100 mm、主板焊接面与底壳触点各 0.010 mm。后两个量是 CAD 理想焊接间隙，尚未测量焊接厚度、公差或整机插接。通电验证需要覆盖 USB 烧录、充电温升、弯折与马达振动。

Gerber 的 F.Mask 是正面覆盖膜开口，B.Mask 表示反面覆盖。此板为两端焊接的转接件，没有 SMT 物料。设计数据和压合尺寸用于工程试样，USB 差分线等长，受控阻抗及整机 USB 连接质量待实测。
