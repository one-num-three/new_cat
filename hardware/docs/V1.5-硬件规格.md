# 猫鼠手环 V1.5 硬件规格（原型版）

## 1. 产品定位

户外真人猫抓老鼠的游戏手环，一场 20 人，一局约 20 分钟，每人都带手机。

- 手环负责：碰撞检测、**NFC 抓捕 / 解救 / 拾取道具**、灯环、振动、蜂鸣、按键
- 手机小程序负责：GPS 定位、联网、实时地图、动态码兜底（已有 `new_cat` 微信小程序）
- 服务器负责：规则裁决、状态同步、反作弊（沿用现有 `cat-mouse-server` v2 的 50 m GPS 距离与 5 s 新鲜度校验）

```
手环 ──BLE──> 手机小程序 ──4G/5G (WSS)──> 服务器 (2核4G / 5Mbps)
  │
  └──NFC (1~3cm)──> 其他手环 / 道具卡 / 手机（绑定）
```

## 3. 为什么每个手环都要“读卡器 + 卡模拟”

两个读卡器互相碰时，双方都在“发射场”，谁也读不到谁。所以手环必须能**切换身份**：

- **Poll（读卡）**：主动发射场，去读别的手环或道具卡
- **Listen（卡模拟）**：伪装成一张卡，等别人来读

RC522 只能读卡、不能模拟卡，**所以原型必须用 PN532**（读卡和模拟卡都支持）。量产时换成 PN7160 / ST25R3916B，体积和功耗都更好。

### 按角色决定 Poll / Listen（固件已实现）

NFC 平时**不开**（省电），只有在**检测到碰撞**或**按下按键**时才打开一个窗口（默认 1.5 秒）：

| 当前角色 | NFC 窗口内的行为 | 能做什么 |
|---|---|---|
| 猫 CAT | 全程 Poll | 抓老鼠、捡道具 |
| 自由的鼠 MOUSE | Listen 和 Poll 交替（600 ms / 300 ms） | 被抓、解救队友、捡道具 |
| 被抓的鼠 JAILED | 全程 Listen | 等队友来救 |
| 大厅 LOBBY（未开局） | 长按按键后 Listen 30 秒 | 手机碰手环完成绑定 |

### 手环之间的握手（自定义 APDU）

1. 读卡方发送 `SELECT AID = F0 43 4D 42 41 4E 44`（"CMBAND"）
2. 读卡方发送 `HELLO`，带上自己的 ID、角色、队伍、场次
3. 被读方回复自己的 ID、角色、队伍、场次、状态

**双方都拿到了对方的身份**，各自通过 BLE 上报给手机，服务器去重并裁决。

### 手机绑定（NDEF 卡模拟）

手环在 Listen 状态下会模拟一张 **NFC Forum Type 4 标签**，里面是一个 URL：

```
https://你的域名/b?id=<手环ID>
```

- 安卓：小程序里调用 NFC 接口读取，或者系统直接打开链接
- iPhone：系统原生就能读这类 NDEF 标签，弹出链接通知。可以配成**微信小程序的 URL Scheme / 普通链接二维码规则**，点一下直接进入小程序的绑定页
- 兜底方案：手环背面印二维码

URL 前缀可以通过 BLE 指令修改，保存在手环的 NVS 中。

## 4. 玩法规则建议（和硬件配套）

- **抓捕 = 两个手环“碰住 0.5 秒”**。NFC 握手需要 100~300 ms，轻轻擦一下可能读不到。把“碰住”设计成一个仪式动作，体验反而更好
- 服务器校验：双方 GPS 距离 < 100 m、场次一致、角色合法，才判定成功
- 道具卡（NTAG215）藏在场地里：加速、隐身（灯环熄灭 30 秒）、护盾、雷达（手机显示最近的猫）
- 猫靠近提醒：手机扫描附近手环的 BLE 广播（广播包里带角色信息），猫在约 10 米内时，鼠的手环“心跳”振动

## 5. 原型接线（XIAO ESP32C3）

| XIAO 引脚 | GPIO | 连接 | 说明 |
|---|---|---|---|
| D4 / D5 | 6 / 7 | **I2C 总线**：LIS2DH12 + PN532 | PN532 拨码开关拨到 I2C 模式 |
| D1 | 3 | LIS2DH12 INT1 | 碰撞中断，**可从深度睡眠唤醒** |
| D2 | 4 | 按键 → GND | 内部上拉，**可从深度睡眠唤醒**（C3 只有 GPIO0~5 能唤醒） |
| D0 | 2 | 电池分压（2×200 kΩ，接 BAT+ 和 GND） | ADC 测电量（Seeed 官方方案同款） |
| D3 | 5 | AO3400 栅极 → 马达 | 马达两端反并 1N4148，栅极加 100 kΩ 下拉 |
| D6 | 21 | WS2812B DIN（串 330 Ω） | 灯环 VDD 接**电池正极** |
| D7 | 20 | 无源蜂鸣器（经 S8050 三极管） | |
| D10 | 10 | PN532 RSTPDN（可选） | 不接也能工作 |
| D8 | 8 | 预留：灯环电源开关 | 启动配置引脚，谨慎使用 |
| D9 | 9 | 板载 BOOT 键 | 不要外接 |
| 3V3 | — | PN532 VCC、LIS2DH12 VCC | |
| BAT+ / BAT− | — | 锂电池（经拨动开关） | 背面焊盘 |

## 6. 功耗预算（250 mAh）

| 部件 | 平均电流 |
|---|---|
| ESP32-C3（BLE 连接，Wi-Fi 关闭） | 15~25 mA |
| 灯环（12 颗，亮度 30~50%，动画） | 40~80 mA |
| PN532（只在窗口内工作，按每分钟约 10 次窗口估算） | 3~8 mA |
| LIS2DH12 | < 0.1 mA |
| 马达 + 蜂鸣器（偶尔） | ~5 mA |
| **合计** | **约 65~120 mA → 2~3.5 小时** |

> 白天户外需要更高亮度，灯环是最大的变量。原型阶段请实测“10 米外能看清颜色”所需的最低亮度。

## 7. 原型阶段要验证的指标

| 指标 | 目标 |
|---|---|
| 碰住 0.5 秒的 NFC 握手成功率 | ≥ 95% |
| 误触发（没碰却判定成功） | 0 |
| 灯环在白天 10 m 外可辨识 | 是 |
| 跑动中能感觉到振动 | 是 |
| 实际续航（亮度 40%） | ≥ 2 小时 |
| 一部手机连一个手环，锁屏 / 切后台 | 记录断连情况（iOS 重点测） |
