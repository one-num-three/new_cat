## 统一设计语言

- 橘白圆润小猫、炭灰小鼠；天空蓝、草地绿、奶油白背景与深青文字。
- 扁平 2D、清晰轮廓、统一圆角和按钮；不增加积分、商店、技能或其他玩法。
- 顶部角色 / 捕获目标 / 时间，地图主导，底部集中主动作；详情放一个抽屉。
- 人员名单和管理动作以服务器授权为准；样例的“再来一局 / 恢复 / 紧急暂停”表示房主视角，不代表普通玩家有管理权限。
- 公园地图是美术示意图，**不是现场地理底图或实际定位**。实现时保留真实地图、服务端状态、原生文字和可访问控件，不把整张页面 PNG 当运行页面。
- 动态码图仅为“演示码 / 不可扫描”；真实码、有效期、倒计时、胜负和位置仍来自现有运行流程。

## 固定提示词与证据

- [PROMPTS.md](PROMPTS.md)：公共风格提示词、每次实际生成与修正提示词、输入引用。
- [screens.json](screens.json)：选中图、原始输出、SHA-256、尺寸和现有预览路线。
- [REVIEW.md](REVIEW.md)：逐页目视检查、修正记录和落地注意项。
- [VERIFICATION.txt](VERIFICATION.txt)：文件完整性、原始图复制一致性、旧美术冻结检查与 ZIP 验证。

## 使用顺序

首页 → 创建 / 加入 → 房间准备 → 躲藏 → 猫 / 鼠追逐 → 动态码 / 预警 → 本局结果。
出局、暂停、重连为条件状态；猫胜 / 鼠胜 / 取消为三个互斥结局。调试台与详情抽屉是额外界面，不能理解为新增游戏模式。

后续落地需保持真实地图可读性：仅在欢迎 / 等待 / 结算等状态使用较大插画，追逐时不让插画遮挡地图或主动作。小屏、大字体、原生地图叠层和真机触控需在代码接入后重新验收；本轮未执行这些运行验证。
