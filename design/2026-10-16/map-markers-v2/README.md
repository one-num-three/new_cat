## 固定提示词与输出

- `prompts.json` 保存本次三次生成的完整实际提示词。后续延续：正面2D、方阶轮廓、深松绿描边、奶白外缘、少量色阶、单枚居中、真实alpha透明；不烘焙文字、场景、阴影底座或卡片。
- 三个 `*-original.png` 均为1254×1254 RGBA原始生成图，保留原始alpha，不手工重绘/抠背景。
- `assets/map-markers-v2/*.png` 为192×192运行图，等比最近邻缩小，保留RGBA。实际48×48显示，图案占画布一部分，视觉高度约33–40px；不会随着地图缩放变大或变扁。
- `manifest.json` 记录原图与运行图SHA256、大小、真实透明像素数量。透明外缘是真实alpha，预览棋盘格仅为网页CSS。
- 重建：`node scripts/build-map-markers.cjs`，需要Node环境可解析sharp。当前机器已具备；小程序与服务端运行无需sharp，不新增运行依赖。

## 工程接入

统一定义：`utils/map-markers.js`。艺术图和微信原生地图共用路径、尺寸与锚点。

- 本人/队友以定位针底端接触坐标。
- 集合点以旗杆脚接触坐标，横向约0.331、纵向约0.839；不能用整张旗帜的画布中心定位。
- 艺术图共享同一等比相机，标记反向抵消地图缩放。文字标签独立绘制；原生图点击才显示气泡，减少遮挡。
- 只消费服务端授权的visiblePositions及公开集合点。敌方情报仍绘制范围，没有新增敌方精确点或定位请求。
- 断线/离页清空策略、房间标定与OSM参考配准不变；未添加位置跳动/漂浮动效，避免尖端脱离真实锚点。
