# 东南大学九龙湖校区：已建与在建，移除规划三维体块

整理日期：2026-10-18。原模型制作日期：2026-10-16。

这是从原始完整 v1 模型制作的独立筛选副本，未重新建模、未修改原版。

## 本包内容

- 东南大学九龙湖_已建与在建_去规划.blend：可编辑场景。
- 新副本的鸟瞰、俯视预览已实际渲染并另行保留；为控制附件大小，本ZIP不附大预览PNG，可从本场景重新渲染。
- data/buildings_保留331构件.json：与本副本一致的建筑数据。
- 分类审计.json、重开验证.json：删除范围、保留数量和打开验证。
- textures/：两张原始地表与规划参考纹理，亦已内嵌进 .blend。

## 精确筛选规则

按原文件建筑根对象已有的 status 属性处理，不重新判断建设进度。

- existing：原有 302 个，全部保留。
- under_construction：原有 29 个，全部保留。
- planned：原有 108 个，全部删除；随同删除其 108 个子屋顶，共移除 216 个对象。
- 保留 331 个建筑体量构件；构件数不等于楼栋数。
- 兰园 E3/E4/E5 的 11 个 existing 构件全部保留。
- 439 个建筑根对象均有明确分类，未发现 status 缺失或未知的建筑根对象。
- 8 个独立坡屋顶无 status，但原命名明确归属已建本科教学楼 A1_bar_1 至 8，全部保留。
- 地形、道路、桥、水体、示意植栽、相机和灯光作为非建筑场景元素保留。

## 重要：这不是完整的2026现状测绘

本副本只删除 planned 的三维建筑体块及其屋顶。示意地表贴图由 2025 官方规划图分类生成；原官方规划图对照面也保留但默认隐藏。两张贴图没有重绘或涂抹，仍可能含规划建筑的二维轮廓、地表色块、规划道路与场地关系。规划体块被删除，不代表其位置的真实现状已经核实。

分类底本为 2025-06-30 官方总图，兰园状态按用户 2026-10-16 的更正保留为已建，其余状态沿用原模型，未逐项更新到 2026-10-18。大部分建筑高度、轮廓及植栽仍是示意估算；不用于施工、测量、精确楼高比较或室内导航。

## 打开与可移植性

使用 Blender 4.3 或更新版本直接打开 .blend，不需要外部 Blender 插件。1 Blender 单位约表示 1 米，北向为 +Y；并非地理配准。两张纹理均已内嵌，纹理路径也改为相对 textures/ 路径。解压到其他文件夹仍可打开。

相机 01 为全校鸟瞰，02 为正北俯视，03 为图书馆与教学区。保存的默认相机为 01。在建建筑仍使用原版陶土橙色；估高和高度证据标记沿用原文件。

本包不含网页 viewer、GLB/GLTF，也未部署到网站或用户设备。需要完整规划方案时，请打开另外交付的“完整原版_含规划”压缩包。
