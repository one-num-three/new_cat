## 导出与简化

使用官方 Blender 4.3.2，便携包 SHA-256：`933a62a770c941e316535f893629ff106ddd2aa5a956f0081ec557439073d4f6`。

```powershell
& '.local-tools/blender-4.3.2-windows-x64/blender.exe' --disable-autoexec --background --python scripts/export-jiulonghu-runtime.py
node scripts/build-model-reference.cjs --verify
```

导出器关闭自动执行，不运行模型内嵌文本。保留全部 331 个建筑底层网格及独立屋顶；省略倒角修改器，将 3246 个装饰树实例均匀抽样为 720 个。合并为 2 批静态几何、27992 个三角形；位置按 0.1 个模型单位量化。二进制格式见导出脚本。原始 `.blend` 不改。

`ground.jpg` 为源 `landcover_schematic.png` 用 sharp 按宽 1024、JPEG quality 83 编码，未改地表内容。运行分包约 1.24 MiB，最终精确大小以交付证据为准。缓存工具不打入小程序。

## 地理含义

原模型没有地理坐标，源规划图北向 +Y、人工估算 1.9 米/图像素。不能直接套用像素艺术图的控制网。

新参考用保存的 OSM 建筑轮廓与原规划图模型组的包围盒中心独立拟合仿射变换。图书馆、体育馆、行政楼、橘园食堂、钟山书院、能环楼参与拟合，纪忠楼作为留出图面检查。其误差约 7.97 源图像素，**不是现场 GPS 误差或定位精度承诺**。`fieldVerified=false`。GCJ-02 显式逆换算到 WGS84，再投影到模型；超过有限场地底座范围拒绝显示，切实时地图核对。用户反馈点 31.882368,118.828049 已作为模拟显示验证。

构件数量不等于独立建筑数。状态沿用源模型资料，未逐栋核验 2026 年现状；多数高度为估算。去规划版仅删除规划 3D 构件，地表底纹仍含规划道路/轮廓。无室内、碰撞、可通行路线、楼层高度定位或建筑遮挡判定。

## 渲染与恢复

真机使用离屏 WebGL→2D 画布合成；输入或授权位置变化时重绘，无常驻动画循环。开发工具出现原生画布在截图中盖住所有叠层的问题，因此仅 `platform=devtools` 以最多约 8.3 Hz 的本地 PNG 图像显示同一渲染结果；无需网络或临时文件。该速度不是手机性能数据。

隐藏页面清空标记/预览并取消帧，卸载释放缓冲、纹理和程序；加载晚回调不能重建已离开的组件。断线清空授权点/线索。画布错误提供切回像素图的按钮。真机 GPU 兼容性、触摸手感、发热/耗电、长时间往返切换与现场 GPS 尚待设备验证。
