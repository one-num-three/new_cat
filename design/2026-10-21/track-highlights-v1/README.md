# 起终点旗子与轨迹亮点海报

制作日期：2026-10-21。沿用原版晴日像素、不规则草地花朵边框。由内置 image_gen 生成，完整提示词见 prompts.json。

## 直接使用

- start-flag-192.png / start-flag-96.png：绿色“起点”，真实透明 PNG。
- finish-flag-192.png / finish-flag-96.png：橙红色“终点”，真实透明 PNG。
- start-original.png / finish-original.png：独立原稿，保留透明通道。
- highlights-poster.png：加入两个轨迹亮点的完整海报效果图。
- highlights-poster.jpg：分享预览版，约586KB。
- manifest.json：实际尺寸、哈希、透明计数及旗杆脚锚点。

海报文案为“你在这里跑得最快”“你在这里离猫最近”。标记位置仅是构图示意，已在图中明确标注“标记位置示意”；没有预填速度、最近距离、里程、时间、热量，也没有预画轨迹线。

## 元素定位

旗子的地图接触点在旗杆脚，而不是整张 PNG 的中心。manifest.json 每枚 sprites.anchor 给出相对完整画布的 u/v。

```javascript
// x、y 是已投影到海报的真实地理点；w、h 为贴图显示尺寸。
ctx.drawImage(flag, x-anchor.u*w, y-anchor.v*h, w, h);
```

开始与结束旗分别放在实际参与导出的第一／最后有效轨迹点。发生轨迹缺口时，不应把缺口后的位置伪装成真正的活动开始位置，可按现有导出语义标记“记录起点／记录终点”。

## 两个亮点的数据接入

本目录交付美术与构图示意，未修改对局统计代码。正式导出仍使用 trajectory-share-irregular-v4 中心透明模板，在原地图层动态绘制旗子与气泡，不把本张生图海报作为定位底图。

- 跑得最快：从有效本人轨迹计算，沿用既有时间分段与漂移过滤；用短时间窗内稳定的速度定位，避免将单次 GPS 跳点当作最高速度。文案气泡的指针落在本人真实轨迹点上。
- 离猫最近：使用赛后已授权、时间对齐的数据或服务端派生摘要，只标记本人所在的位置；不因此额外导出猫的完整隐藏轨迹。无有效同步猫数据时省略该气泡。
- 两个点重合或气泡碰撞时需要错开气泡位置，并保留指向真实点的连接线；不要移动地理标记点。某项没有有效数据就不显示。

当前两个亮点只是表现风格。真实位置和统计值均需由“实现猫鼠游戏试点版本”会话接入现有轨迹导出流程。

所有文件直接保留，无压缩包。export.cjs 用 Sharp 做尺寸导出与分享 JPEG 编码，执行 node export.cjs 可复现派生文件；原始图哈希保持不变。
