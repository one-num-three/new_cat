# 猫鼠行动 · 轨迹分享海报

晴日 16-bit 像素风，使用玄武湖环洲／樱洲原画与新猫鼠图标作为参考，由内置 image_gen 生成。

- trajectory-share-poster.png：完整竖版 PNG 原稿。
- trajectory-share-poster.jpg：分享用轻量 JPG，同构图、同尺寸。
- PROMPT.txt：完整生图提示词。
- VERIFICATION.json：实际尺寸、字节数、哈希与数据说明。

包含标题、地点、起终点、轨迹、足迹点、距离／时长／足迹点数据区和品牌落款。海报明确标注“示例数据”及“示意轨迹 · 非真实记录”；3.2 km、42 分钟、8 个足迹点均为设计示例。

这是静态分享海报设计。接入小程序时，地图、路线、统计值应由真实记录动态合成；本图上的轨迹与数字不可作为用户真实记录使用。全部文件直接保存，无压缩包。
