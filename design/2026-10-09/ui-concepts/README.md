# 猫鼠行动：三套视觉方向与动效样片

这些是供选择的视觉探索，当前可运行的小程序页面未被替换。三张概念图由生图模型生成；三段 GIF 是独立绘制的界面动效样片，不连接真实服务。

| 方案 | 视觉性格 | 优点 | 试点需注意 |
| --- | --- | --- | --- |
| A 城市指南 | 明亮纸白、橘色猫、青色鼠、现代城市地图 | 户外阅读直接，角色与主动作醒目 | 概念首页背景较重，落地时需减轻资源体积 |
| B 夜间信号 | 深蓝导航、冰青线索、琥珀预警 | 夜间氛围和动态线索最强 | 白天强光下需要单独测对比度；不能作为唯一日间皮肤 |
| C 户外手册 | 纸张、森林绿、地形线与任务标签 | 与真实场地结合自然，个性最鲜明 | 纸纹只应用于非地图区域，不能牺牲地图文字清晰度 |

## 文件

- `A_城市指南.png` / `.gif`
- `B_夜间信号.png` / `.gif`
- `C_户外手册.png` / `.gif`
- `render_motion.py`：可复现生成三个 GIF 和首帧，运行 `python render_motion.py`。

GIF 共演示：区域线索缓慢脉冲 → 扫码后抓捕确认面板进入 → 双方一致的胜负进度。线索始终是区域，不是鼠的精确位置；蓝点只代表本人位置。动效展示约 3 秒循环，每秒 20 帧，并非真实倒计时或实时网络状态。

## 生成提示词摘要

- A：三屏微信小程序概念板，明亮户外阅读，暖白底、橘色猫、青色鼠，首页、2 猫 6 鼠准备房、地图主屏；顶部阵营/目标/计时，底部主动作，地图只显示区域线索。
- B：相同信息架构，深蓝夜间导航，克制的冰青雷达和琥珀危险提示；鼠地图只有近距警告区，不显示猫的精确坐标。
- C：相同信息架构，纸张与森林绿的户外手册风格，地形线、路径和清晰的安全区，突出地图与主动作。

生图文本、人物数、时间和部分地图标注可能不符合已登记试点规则（例如 B 图进度、C 图活动时长）。它们只用于选择视觉语言；实际实现必须沿用服务端 `pilot-0.2` 的 30 秒躲藏、6 分钟追逐、60% 向上取整捕获目标，并由授权快照填充数据。动画也只是视觉演示，不是已经通过小程序模拟器或真机验证的动效。

## 选择后落地

先统一颜色、字号、间距、按钮和状态组件，再按所选方向调整首页/入房、准备房、地图、动态码、被捕/暂停/重连及结算。试点以小屏、大字体、日光可读性、低端机帧率为验收条件。可以选择一套主视觉，借用另一套的局部动效。
